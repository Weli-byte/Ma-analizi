# ADR 0098 — Android app on Google Play as a Trusted Web Activity (2026-11-01)

Owner decision: publish Welliddia on Google Play; package `app.welliddia.tahmin`; Play App Signing.

## Decision
- The Android app is a Trusted Web Activity generated by Bubblewrap 1.27.0 from `android/twa-manifest.json`: it opens https://mac-tahmin-eight.vercel.app full screen; content, sign-in and
  updates stay the web app's (no second code base, no native permissions, notifications off). Minimum Android 7.0 (API 24: the androidbrowserhelper 2.7.4 library requires it), target API 36.
- Signing: Play App Signing. Google holds the app signing key; the owner holds an UPLOAD key (RSA 4096, PKCS12, alias `upload`, valid 30 years) created on the owner's PC outside the repository
  (`C:\Users\weli1\welliddia-android-key\`, keystore + password file: the owner's backup) and stored as the GitHub secrets `ANDROID_UPLOAD_KEYSTORE_B64` / `ANDROID_UPLOAD_KEYSTORE_PASSWORD`.
  A lost upload key can be reset through Play Console support; the app signing key never leaves Google.
- The site serves `/.well-known/assetlinks.json` from `configs/android/assetlinks.yaml` (public SHA-256 certificate digests: the upload key now, the Play app signing key after the first upload).
  Without the Play key's digest the store build opens with a URL bar.
- The web manifest gains a maskable 512 px icon (full-bleed green, the ball inside the safe zone).
- `.github/workflows/android-build.yml` (manual, with versionCode / versionName; also on pull requests that touch `android/`) builds the `.aab` for Play Console and a signed `.apk` for a test
  install; the keystore is decoded on the runner only and deleted after the build. The generated Android project is not committed.

## Not decided here (owner, Play Console)
Developer account and identity verification, the closed test (12 testers for 14 days for a new personal account), store listing, content rating, target audience 18+, Data safety form,
account deletion URL, the gambling-content questions; the licence gate of ADR 0097 still says NO_GO for a commercial launch.

## Amendment (2026-11-02): app mode for the Play review
- The TWA start URL is `/?app=android`. A script in the page head marks the tab as the app when that query or an `android-app://app.welliddia.tahmin` referrer is
  seen, stores the flag in the tab's sessionStorage (not a cookie: a TWA shares Chrome's cookie jar, so a cookie would also change the plain browser) and adds
  the class `app-android` to `<html>`. The login redirect keeps `?app=android`.
- In app mode CSS hides elements marked `no-app`: the "Tavsiyeler" navigation item and home-page section, the match page's "Tavsiye" tab (betting-style picks
  and the research-only value table) and the Apple / phone sign-in buttons while they are not configured. `/tavsiyeler` redirects to `/` in the app.
- Reason: Google Play's real-money gambling policy is strict about betting tips and odds; the store build shows probabilities and the track record only. The
  website is unchanged. Nothing is removed from the server's HTML (the app hides it); forecasts, models and the API are untouched.
- The `.aab` must be rebuilt (`android-build`) for the new start URL; versionCode stays 1 because nothing was uploaded yet.
