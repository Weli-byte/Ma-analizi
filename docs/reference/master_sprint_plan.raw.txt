 4. VER MODEL

  Temel entity'ler:
  · leagues: league_id, country, name, tier
  · teams: team_id, canonical_name, country
  · fixtures: fixture_id, league_id, season, kickoff_utc, home_id, away_id, status
  · results: fixture_id, score, outcome
  · team_match_stats: shots, xG, xGA, possession, etc.
  · team_ratings: Elo/strength history
  · lineups: timestamp, formation, starters
  · injuries: player/team status + timestamp
  · odds_snapshots: bookmaker, market, selection, decimal odds, timestamp
  · feature_snapshots: fixture, feature_version, information_cutoff, feature values
  · predictions: model, version, probabilities, generated_at, cutoff
  · evaluations: prediction_id, metrics, result
  · experiments: run_id, config, dataset version, git SHA, metrics

  Feature contract: Her feature için source, window, aggregation, available_at ve leakage_rule bulunacak.

  Örnek:

  form_points_5 | results | last 5 | points sum | t-1 | current match excluded
  elo_home | ratings | latest | latest value | t-1 | future rating excluded
  xg_avg_10 | stats | last 10 | mean | t-1 | only completed matches
  lineup_strength | lineups | latest | weighted score | T-lineup | no post-kickoff data
